# 割了么 (GeLeMe) - 专注解决拿不住问题 📉🌾

> **免责声明**：本项目纯属娱乐自嘲小游戏，所有数据均为前端虚构数据，不展示真实股票、不展示真实交易平台，**不构成任何投资建议**。

---

## 🌟 项目简介

「割了么」是一个纯前端实现的单页互动 H5 网页，灵感来源于中文投资社区里“拿不住就去打工、进厂拧螺丝、耕地拿锄头”的自嘲梗。

项目通过金融 App 风格的UI界面与荒诞剧情，带领玩家经历从“死咬牙坚持”到“拿不住重新规划职业”，再到“统一结算工资”、最终被“谎言检测强制梭哈”并生成专属【割了么职业评估报告】的搞笑闭环。

---

## 🚀 核心功能与玩法

1. **第一屏 · 拿不住了吗**：
   - 品牌名「割了么 - 专注解决拿不住问题」，展示极速炒股指数大盘。
   - 提供「我拿得住」与「拿不住了」两大分支。

2. **「我拿得住」持仓挑战**：
   - 第一阶段：收益从 -2.71% 急速跳水至 -8.43%，伴随页面震动与心跳抖动。
   - 第二阶段：本金从 100,000 元蒸发至 47,250 元，触发“你的手正在钻石化”。
   - 最终解锁：官方【钻石手认证勋章】。

3. **「拿不住了」职业规划 4 大分支**：
   - ✂️ **1. 立即割肉**：二次确认“确定卖在最低点吗？”。确认后股票秒拉 +19.98% 大阳线，并颁发“为您成功提供市场流动性”。
   - 🌾 **2. 拿锄头 (长按小游戏)**：长按 3 秒考验握持定力。提前松开提示“锄头也没拿住，建议进厂拧螺丝”；坚持 3 秒获得【耕地资格认证，预估收益：两筐土豆】。
   - 🔧 **3. 进厂拧螺丝 (10秒手速挑战)**：传送带动画 + 10 秒内连续狂点 30 次螺丝。成功计算日薪 86 元、亏损 8600 元与预计 100 天回本工期。
   - 🛵 **4. 送外卖 (同城竞速模拟)**：28分钟完成6单，随机触发“出餐慢、爬28楼、电梯故障、到了别打电话、预计超时7分钟”突发事件。

4. **统一结算 & 谎言检测 (All-In 循环)**：
   - 结账到账 3,842 元劳动所得。
   - 询问“是否全部买入？”，点击“我已经成熟了”时，触发“系统检测到您正在撒谎”，自动执行强制梭哈，股价归零，形成荒诞闭环。

5. **割了么职业评估报告**：
   - 综合评估：股票承受能力、锄头握持能力、螺丝完成率、外卖准时率、本轮亏损金额。
   - 动态生成专属称号（如：钻石手受害者、最低点狙击手、流动性提供者、螺丝逃兵、锄头体验官、职业规划失败者）。
   - 支持 **【保存截图】** (基于 `html2canvas`) 与 **【再割一次】** 重新开局。

## 🛠️ 技术栈

- **框架**：React 19 + TypeScript + Vite
- **样式与UI**：Tailwind CSS v4 + Lucide React 图标库
- **动画**：Framer Motion
- **截图导出**：html2canvas
- **庆祝特效**：canvas-confetti

## 💻 本地运行指南

1. **进入项目目录**：
   ```bash
   cd geleme
   ```

2. **安装依赖**（如已安装可跳过）：
   ```bash
   npm install
   ```

3. **启动开发服务器**：
   ```bash
   npm run dev
   ```
   启动后在浏览器打开终端提示的 `http://localhost:5173` 即可免费体验！

4. **打包构建**：
   ```bash
   npm run build
   ```
   打包完成后会在根目录生成 `dist/` 静态网页目录。

## 📤 怎么发给群友玩？（免费 1 分钟上线方法）

如果您本地不能部署，可以采用以下几种极简且**完全免费**的方式发给群友：

### 方法 1：使用 Vercel（推荐，1分钟自动挂载网址）
在终端项目根目录下运行：
```bash
npx vercel
```
按回车确认后，Vercel 会自动将 `dist` 上传并生成一个永久免费的 `https://xxxx.vercel.app` 链接，直接复制发群里即可！

### 方法 2：使用 Netlify 拖拽或命令行
运行：
```bash
npx netlify-cli deploy --dir=dist --prod
```
或直接打开 [Netlify Drop](https://app.netlify.com/drop)，把打包好的 `geleme/dist` 文件夹拖进去，几秒钟就能获得免费网址！

### 方法 3：局域网/同 WiFi 群友测试
运行：
```bash
npm run dev -- --host
```
终端会输出形如 `http://192.168.x.x:5173` 的局域网 IP 链接，只要群友在同一 WiFi 或连手机热点就能直接打开访问！
